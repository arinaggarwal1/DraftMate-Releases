# DraftMate releases

This repository hosts macOS installers and signed update artifacts for DraftMate. Application source is maintained in a separate private repository.

## Current testing channel

The first prerelease is an Apple silicon macOS sandbox build. It uses test licensing and does not accept real payments. Downloads will appear under Releases after a draft is reviewed and published.

DraftMate is proprietary software. Installing an updater-signed artifact does not imply Apple Developer ID signing or notarization; the initial alpha has not been notarized.

For license or device-transfer support, use the support link in the application.
